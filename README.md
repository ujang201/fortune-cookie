# Fortune Cookie Wisdom for Developers

One original fortune-cookie line for a software developer, written by a
deterministic program (`main.ts`, Node 22) to `/output/entry.txt`.

> The legacy code you curse was written by someone tired, rushed, and certain — exactly like you.

The line is 95 characters — one short, balanced sentence that reads like a
real fortune cookie, says something true about a developer's day (legacy
code, code review, estimates made under pressure), and turns it with a
quiet twist: the person you blame for the mess is a mirror of you.

## Run

```sh
node main.ts
# writes /output/entry.txt (or $OUTPUT_DIR/entry.txt)
```

Deterministic: the same text is written on every run, with no randomness,
no network, and no input.
